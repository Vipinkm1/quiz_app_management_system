# Quiz App Management System

A modern Quiz / Question Management Admin Panel built with React and Vite.

## 🚀 Features

- Add, Edit & Delete Questions
- Category & Subcategory Management
- Question Analytics Dashboard
- Multiple Question Types
  - Single Select
  - Multi Select
  - True / False
- Image Upload Support
- Audio Upload Support
- Rich Text Question Editor
- LocalStorage Data Persistence
- Question Reports & Metrics
- Responsive Admin Dashboard UI

---

## 🛠️ Tech Stack

- React.js
- Vite
- JavaScript
- CSS
- TipTap Editor
- Lucide React Icons

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/Vipinkm1/quiz_app_management_system.git
```

Go to project folder:

```bash
cd quiz_app_management_system
```

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm run dev
```
